Need to share just two pages from a report, assignment, invoice or longer document? Pagrix works as a PDF page extractor on Android, letting you choose individual pages or a continuous page range and save the result as a separate PDF.

Quick guide

Extract PDF pages step by step

The labels below match the current Pagrix Split PDF screen.

Choose the right mode

Use Selected Pages for individual pages. Use Page Range when the pages are consecutive.

  1. 01

    Launch Pagrix and open Split PDF

    Open Pagrix on your Android device. In the PDF tools, tap Split PDF.

  2. 02

    Select the PDF document

    Tap Select PDF, then choose the document that contains the pages you want to extract.

  3. 03

    Choose Selected Pages or Page Range

    Under Split Mode, choose Selected Pages to pick individual pages or Page Range to extract one continuous section.

  4. 04

    Specify the pages to extract

    For Selected Pages, tap the page thumbnails you need. For Page Range, enter the first page under From Page and the last page under To Page.

  5. 05

    Select the output destination

    Tap Save to and choose where the new PDF should be stored. Pagrix needs a destination before it can create the output.

  6. 06

    Tap Create PDFs

    Review the output summary, then tap Create PDFs. The button stays disabled until the source PDF, valid page selection and required save destination are ready.

Method 01

Extract selected pages from a PDF

Selected Pages is useful when the pages you need are not next to each other—for example, pages 2, 5 and 9 of a report. Select only the relevant page thumbnails, choose Save to, and create a new PDF from that selection.

Split Mode Selected Pages Page thumbnails Save to → Create PDFs

Method 02

Split a PDF by page range

Page Range is faster when you need a continuous section of a longer document—for example, pages 10 through 18. Enter the beginning and ending page numbers, select the save destination, then create the output.

Split Mode Page Range From Page → To Page Save to → Create PDFs

Before you create the output

A quick check prevents the common hold-up.

  • Confirm the page numbers. Page numbers refer to the PDF pages shown in Pagrix.
  • Check the output summary. It shows how many PDF files and pages will be created.
  • Choose Save to. If Create PDFs is unavailable, confirm that a valid selection and destination are set.

Frequently asked

Extracting PDF pages with Pagrix

Can I extract individual pages that are not next to each other?

Yes. Choose Selected Pages in Split Mode, then tap the individual page thumbnails you want in the new PDF.

How do I extract a continuous section of a PDF?

Choose Page Range, then enter the first page under From Page and the last page under To Page.

Why is the Create PDFs button disabled?

Create PDFs becomes available after Pagrix has a source PDF, a valid page selection and the required output destination selected under Save to.

Where is the extracted PDF saved?

Pagrix saves the output to the destination you choose under Save to.

Can Pagrix split every page into a separate PDF?

Yes. The current Split PDF screen also includes an Every Page mode for creating one PDF per page. This guide focuses on Selected Pages and Page Range.

Does extracting pages change the original PDF?

Pagrix creates PDF output at the destination you select. Your source document remains in its existing location.
